# Lucas Kailembo Portfolio

A responsive personal portfolio website built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Files
- `index.html` — website structure/content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, active navigation and dynamic year

## Run
Open `index.html` in a browser.

## Customize
Replace/add project cards in the Projects section and add your GitHub/LinkedIn links when available.
